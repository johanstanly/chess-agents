# engines — chess engine program
The Stockfish program lives here on your computer only. It is too big for GitHub, so it is not uploaded.

To set it up on a new computer: download Stockfish for Windows from https://stockfishchess.org/download/, unzip it, and put the `stockfish` folder here (so that `engines/stockfish/stockfish-windows-x86-64-universal.exe` exists). The programs find it automatically.
