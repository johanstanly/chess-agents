# Stockfish (browser version)

The evaluation bar uses **Stockfish 18**, a free and open-source chess engine,
compiled to run inside the web browser ("lite single" build).

- Source code: https://github.com/nmrugg/stockfish.js (browser build) and https://github.com/official-stockfish/Stockfish
- Licence: GNU General Public License v3 — see `Copying.txt` in this folder.
- The files here are unmodified copies of `stockfish@18.0.8` from npm.
