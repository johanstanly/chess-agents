# docs — the website
Everything in this folder is published by GitHub Pages at https://johanstanly.github.io/chess-agents/
- index.html, landing/, hero.mp4, knight.svg — the front page (built from `landing/`; don't edit these by hand)
- results.html — the results of the experiment
- replay.html — the game replay with Stockfish analysis
- live.html — the 3D tavern view (models/ holds its characters and furniture)
- js/ — code that makes the pages work
- css/ — colours, sizes and styling
- pieces/ — our own wood-style piece drawings
- engine/ — Stockfish for the browser (analysis on the replay page)
- games/ — one diary file per game
- data/ — the results table and Magnus's final notebook, used by the results page
